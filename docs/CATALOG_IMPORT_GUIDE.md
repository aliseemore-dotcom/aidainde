# Руководство по импорту каталога

Для тех, кто готовит данные (в том числе ChatGPT): **ресторанов, кафе, баров, культурных площадок, мероприятий, идей на дом**. Всё ниже соответствует реальной схеме проекта и проверяется автоматическими тестами: примеры из этого документа проходят ту же валидацию, что и боевой импорт.

## 1. Главные правила

1. Нельзя выдумывать. Нет данных — поле **не указывают** или ставят `null`. Цена не найдена — `priceMin`/`priceMax` **не указывают** (это не «бесплатно»); бесплатно — только `0`.
2. У каждой записи есть **ссылка на первоисточник** (`sourceUrl`) и **дата проверки** (`verifiedAt`): день, когда данные сверены с официальной страницей.
3. Файл — **JSON-массив** в UTF-8. Один объект — одна запись. Поле `type` обязательно: `place`, `event` или `activity`.
4. Поле `status` в файле **не указывают** (допустим только `"draft"`): всё загружается **черновиками**. Публикует человек в админке после просмотра.
5. Демонстрационные данные не загружаются: `isDemo` не указывают (или `false`).
6. Незаполненные заглушки вида `[ЦЕНА]`, `[НАЗВАНИЕ]` запрещены: такая запись отклоняется.
7. **Лишних и неизвестных полей быть не должно**: опечатка в названии поля (`websiteURL` вместо `websiteUrl`) отклоняет запись с понятной ошибкой. Используйте только поля из таблиц ниже.
8. Тексты — обычный текст без HTML и Markdown. Описание: 1–3 предложения своими словами, не копия чужого сайта.

### Форматы значений

| Что | Формат |
|---|---|
| Дата и время | ISO 8601 с часовым поясом Казани: `"2026-10-17T19:00:00+03:00"` |
| Дата проверки | так же: `"2026-10-12T12:00:00+03:00"` |
| Цена | целое число рублей (`800`), не строка, без «₽» |
| Ссылки | только `http://` или `https://` |
| slug | латиница в нижнем регистре, цифры и дефисы, до 80 символов: `kofeynya-na-baumana`. Уникален среди записей одного типа. Транслитерация: ж→zh, х→kh, ц→ts, ч→ch, ш→sh, щ→shch, ю→yu, я→ya, ы→y, ъ и ь опускаются |
| Булевы поля | `true`, `false` или `null` (не знаем) |
| Теги | массив ключей из раздела 5, например `["venues", "venue_quiet"]` |

## 2. Поля записей

«Для импорта» — без этого запись отклоняется. «Для публикации» — без этого админка не даст опубликовать (черновик загрузится, но его придётся дополнять руками).

### Общие для всех типов

| Поле | Тип | Для импорта | Описание |
|---|---|---|---|
| `type` | `"place"` \| `"event"` \| `"activity"` | **да** | Вид записи |
| `slug` | строка | **да** | Адрес страницы |
| `title` | строка 2–160 | **да** | Название |
| `description` | строка 10–5000 | **да** | Описание |
| `tags` | массив ключей | нет, но **для публикации обязателен минимум один тег-направление** | См. раздел 5 |
| `ageMin`, `ageMax` | целые ≥ 0 | нет | Возраст. `ageMin: 18` — только взрослым (такие записи не показываются семьям с детьми) |
| `media` | массив | нет | Фото (см. ниже) |

### `place` — постоянное место (ресторан, кафе, бар, музей, театр, парк…)

| Поле | Тип | Для импорта | Описание |
|---|---|---|---|
| `kind` | ключ типа места | нет (рекомендуется) | `restaurant`, `cafe`, `museum`… см. раздел 5 |
| `address` | строка ≥ 3 | **да** | Улица и дом |
| `sourceUrl` | ссылка | **да** | Первоисточник |
| `verifiedAt` | дата-время | нет, но желательно | Когда проверено |
| `district` | строка | нет | Район |
| `lat`, `lng` | числа | нет | Координаты, например `55.7961`, `49.1064` |
| `websiteUrl`, `bookingUrl` | ссылки | нет | Сайт, онлайн-запись |
| `contactsJson` | объект `{phone?, email?, social?}` | нет | Контакты |
| `openingHoursJson` | объект «подпись → часы» | нет | `{"Пн–Пт": "10:00–22:00", "Сб–Вс": "11:00–23:00"}` |
| `priceMin`, `priceMax` | целые ≥ 0 | нет | Диапазон цен, ₽ |
| `priceUnit` | `per_person` \| `total` \| `unknown` | нет | С человека / за всех / неизвестно (по умолчанию `unknown`) |
| `minParticipants`, `maxParticipants` | целые ≥ 0 | нет | Ограничения по размеру компании |
| `soloFriendly`, `joinOpenGroup`, `requiresBooking` | boolean \| null | нет | Можно одному / можно присоединиться к чужой группе / нужна запись |
| `indoorOutdoor` | `indoor` \| `outdoor` \| `both` \| `unknown` | нет | Внутри / на улице / и там и там (по умолчанию `unknown`) |
| `durationMinutes` | целое ≥ 0 | нет | Типичная длительность |

### `event` — мероприятие в конкретные дату и время

| Поле | Тип | Для импорта | Описание |
|---|---|---|---|
| `startsAt` | дата-время | **да** | Начало (время Казани, `+03:00`) |
| `sourceUrl` | ссылка | **да** | Первоисточник |
| `verifiedAt` | дата-время | нет, но **для публикации и попадания в подборку обязательно** | Когда проверено |
| `placeSlug` | строка | нет (рекомендуется) | `slug` площадки (`place`), на которой проходит событие. Площадка должна быть **выше в этом же файле** или уже загружена. Не найдена — событие пропускается с понятной причиной |
| `placeId` | uuid | нет | То же по идентификатору; обычно не нужен, используйте `placeSlug` |
| `endsAt` | дата-время | нет | Окончание |
| `expiresAt` | дата-время | нет | После этого момента события нет в подборке |
| `priceMin`, `priceMax`, `priceUnit` | как у места | нет | Стоимость билета |
| `ticketsUrl` | ссылка | нет | Страница билетов или регистрации (у организатора) |
| `capacity` | целое ≥ 0 | нет | Сколько всего мест |
| `indoorOutdoor` | как у места или `null` | нет | `null`/не указано — наследуется от площадки |
| `soloFriendly`, `joinOpenGroup`, `requiresBooking` | boolean \| null | нет | Как у места |
| `occurrences` | массив сеансов | нет | Дополнительные сеансы повторяющегося события (ниже) |

Основной сеанс — `startsAt`/`endsAt` самого события; `occurrences` — **дополнительные** даты: `{"startsAt": "…", "endsAt": "…"?, "status": "published" | "cancelled" | "sold_out", "ticketsUrl": "…"?}`.

### `activity` — идея на дом (без адреса, даты и бронирования)

| Поле | Тип | Для импорта | Описание |
|---|---|---|---|
| `stepsRichText` | строка | нет | Шаги. Абзацы — пустой строкой, списки — строками с `- ` |
| `requiredMaterialsJson` | массив строк | нет | Что понадобится |
| `durationMinutes` | целое ≥ 0 | нет | Длительность |
| `costMin`, `costMax` | целые ≥ 0 | нет | Примерная стоимость, ₽ (`0` — бесплатно, не указано — неизвестно) |
| `minParticipants`, `maxParticipants` | целые ≥ 0 | нет | Размер компании |
| `sourceUrl` | ссылка | нет | Источник, если есть |

### `media` — фото (необязательно)

`[{"url": "https://…", "alt": "Что на фото", "rightsStatus": "owned" | "licensed" | "permission" | "unknown", "order": 0}]`.
Допустимы **только `https` и только домены из переменной `IMAGE_HOSTS`**; иначе запись отклоняется. Права «unknown» — фото на сайте не показывается. Если домены не согласованы, поле `media` не указывайте: фото добавляют позже в админке.

## 4. Обязательные поля — сводка

| Тип | Для импорта (иначе отклонена) | Дополнительно для публикации | Дополнительно для попадания в подборку |
|---|---|---|---|
| `place` | `type`, `slug`, `title`, `description`, `address`, `sourceUrl` | минимум один тег-направление | опубликованное место |
| `event` | `type`, `slug`, `title`, `description`, `startsAt`, `sourceUrl` | тег-направление, **`verifiedAt`** | `verifiedAt`, сеанс на выбранную дату, не отменено и не прошло |
| `activity` | `type`, `slug`, `title`, `description` | минимум один тег | опубликованная идея |

## 5. Категории, теги, типы мест

Теги — **единый словарь** проекта: им пользуются и каталог (фильтры, админка), и алгоритм подбора. Других значений нет: неизвестный ключ отклоняет запись. Ставьте только то, что **правда**: лишний тег вредит подбору сильнее, чем отсутствующий.

### Как классифицировать запись

| Ось | Куда записывается | Что выбрать |
|---|---|---|
| Вид досуга | `tags`: направление + подтип | Одно из `walks`, `venues`, `games`, `culture`, `wellness` (для идей на дом — `home`) и 1–2 подтипа |
| Тип места | `kind` | Ресторан, кафе, музей… (только для `place`) |
| Настроение | `tags`: `mood_*` | 1–2 тега |
| Состав компании | `tags`: `company_*` | Для кого подходит; можно несколько |
| Атмосфера | `tags`: `energy_*` (людно/для своих/тихо) и `venue_quiet`, `well_cozy`, `social_*` | 1–2 тега по факту |
| Уровень активности | `tags`: `load_*` (сидя → высокая) и `effort_*` для идей на дом | 1 тег |
| Формат помещения | поле `indoorOutdoor` (`indoor`, `outdoor`, `both`); идеи на дом — всегда «дома» | Не знаете — `unknown` или не указывайте |
| Ограничения и доступность | `tags`: `adult_only`, `car_required`, `step_free`, `transit_accessible`; `ageMin` | Только при точных данных |

Минимум для хорошей записи: направление, 1–2 подтипа, 1–2 настроения, «для кого», энергия, нагрузка, формат помещения.

## 6. Дубликаты

Проверка идёт при импорте дважды: **внутри файла** и **с уже загруженным каталогом**. Совпавшая запись пропускается, в отчёте называется существующая.

| Тип | Дубликат, если совпадает |
|---|---|
| `place` | название **и** адрес |
| `event` | название **и** время начала (до минуты) **и** площадка |
| `activity` | название |

Сравнение не учитывает регистр, «ё/е», кавычки и знаки препинания. В адресе не учитываются слова «ул., улица, проспект, пер., наб., пл., д., дом, г., Казань…» и порядок слов: `ул. Баумана, 7` = `Баумана ул., д. 7, Казань`. Сеть заведений по **разным** адресам — не дубликаты. Отдельная проверка по `slug`: занятый slug пропускает запись.

Не распознаётся автоматически: одно заведение под разными названиями (например, «Кафе Х» и «Х»). Такие случаи проверяются вручную.

## 7. Как загрузить

Файл — один JSON-массив. Порядок важен: **сначала места, потом события**, которые на них ссылаются.

```bash
# 1. Проверка без записи (можно запускать где угодно): покажет все ошибки
npm run content:import -- файл.json --dry-run

# 2. Загрузка черновиками в боевую или тестовую базу
DATABASE_URL="postgres://…" IMAGE_HOSTS="img.example.org" npm run content:import -- файл.json

# 3. После загрузки: просмотр и публикация в админке, затем проверка перед запуском
DATABASE_URL="postgres://…" npm run content:check
```

- `--dry-run` ничего не пишет. Для записи нужен `DATABASE_URL` (локальная встроенная база командой не обслуживается).
- `IMAGE_HOSTS` нужен, только если в файле есть `media`.
- Ошибки печатаются по номеру записи (`#3 (slug): …`). Код выхода `0` — всё загружено; `1` — часть записей отклонена или пропущена.
- Загруженное — **черновики**. Опубликовать их можно только в админке (`/admin`): там видны недостающие данные и доступен предпросмотр.
- Таблицы Excel/Google Таблиц можно привести к этому JSON; готовый путь для таблиц — `npm run content:csv` (см. README).

## 8. Чек-лист перед загрузкой

- [ ] Файл — валидный JSON-массив, у каждого объекта есть `type`.
- [ ] Нет полей `status`, `isDemo` и неизвестных полей.
- [ ] Нет заглушек вида `[...]`.
- [ ] У каждой записи: `slug`, `title`, `description`, `sourceUrl` (кроме `activity`), у места — `address`, у события — `startsAt`.
- [ ] `verifiedAt` указана; у событий обязательна.
- [ ] Цена: `0` только для бесплатного; неизвестная — не указана.
- [ ] Теги только из справочника; у каждой записи есть направление.
- [ ] События идут после своих площадок; `placeSlug` совпадает со slug площадки.
- [ ] Даты в формате `…+03:00`.
- [ ] `--dry-run` прошёл без ошибок.
